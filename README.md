# Latent-Liver

Official code repository for **“Real-Time Liver Deformation Tracking from a Single X-Ray Projection Using a LoRA-Adapted Latent Point Cloud Diffusion Model.”**

![Latent-Liver real-time deformable liver and tumor motion tracking](Latent-Liver_Supplementary_Movie.gif)

## Overview

Latent-Liver is a population-pretrained and patient-adapted framework for markerless estimation of three-dimensional deformable liver and tumor motion from a single X-ray projection. It is designed to address the low soft-tissue contrast of onboard X-ray imaging while maintaining the sub-second inference speed required for real-time motion management in image-guided radiotherapy.
